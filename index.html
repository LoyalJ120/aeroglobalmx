Servicios

01 · GEOMÁTICA

Topografía

Levantamientos del terreno para construcción, ingeniería, infraestructura, desarrollos y análisis de superficies.

02 · CAPTURA

Tecnología

Equipo especializado para cada misión.

Trabajamos con plataformas y sensores DJI seleccionados según el objetivo del proyecto.

DJI · LiDAR

Zenmuse L2

Sistema aéreo de LiDAR de alta precisión que integra LiDAR, IMU de alta precisión y cámara RGB 4/3 para adquisición de datos geoespaciales.

  • Nubes de puntos 3D
  • Levantamientos topográficos
  • Modelos y análisis del terreno
  • Curvas de nivel y productos cartográficos
  • Captura RGB para complementar el levantamiento
DJI · Multisensor

Zenmuse H30T

Sensor multisensor para inspección y reconocimiento, combinando imagen visible, zoom, térmica infrarroja y telémetro láser.

  • Inspección visual detallada
  • Inspección térmica
  • Reconocimiento y documentación aérea
  • Detección y análisis de diferencias térmicas
  • Medición de distancia mediante telémetro láser
DJI · PLATAFORMA EMPRESARIAL

DJI Matrice 400

Plataforma aérea empresarial de larga autonomía para misiones de topografía, cartografía, inspección, ingeniería y construcción. Su diseño admite cargas útiles especializadas como LiDAR y sistemas multisensor.

  • Hasta 59 minutos de vuelo en las condiciones de referencia de DJI
  • Capacidad de carga útil de hasta 6 kg
  • RTK para posicionamiento de alta precisión
  • Sistemas de percepción con LiDAR y radar mmWave
